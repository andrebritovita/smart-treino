# Política de Privacidade – Smart Treino
**Última atualização: 11/11/2025**

A presente Política de Privacidade descreve como o aplicativo **Smart Treino** coleta, utiliza, armazena e protege os dados pessoais dos usuários, em conformidade com a **Lei Geral de Proteção de Dados (LGPD – Lei nº 13.709/2018)**.

## 1. Dados Coletados
O Smart Treino coleta apenas os dados necessários para funcionamento do aplicativo.

### 1.1 Dados fornecidos pelo usuário
- Nome
- E-mail
- Senha (criptografada)
- Dados de treino criados manualmente
- Preferências e histórico de uso

### 1.2 Dados gerados automaticamente
- Identificador único do usuário (UID Firebase)
- Informações de dispositivo (modelo, versão Android)
- Token de notificações FCM
- Logs de erro (Crashlytics, opcional)

### 1.3 Dados enviados para IA (Google Gemini)
Quando o usuário solicita geração de treino:
- Objetivo do treino
- Nível físico
- Informações fornecidas voluntariamente para personalização

Nenhum dado sensível (saúde clínica, doenças, condições médicas) é enviado automaticamente — apenas se o próprio usuário digitar.

## 2. Finalidades do Tratamento
Os dados coletados são utilizados para:

- Autenticação do usuário
- Sincronização de treinos entre dispositivos
- Geração de conteúdo personalizado por IA
- Envio de notificações push
- Melhorias de desempenho e estabilidade
- Suporte e atendimento ao usuário

## 3. Base Legal
O tratamento de dados ocorre com base em:

- **Consentimento** (art. 7º, I)
- **Execução de contrato** (art. 7º, V)
- **Legítimo interesse** (art. 7º, IX)

## 4. Armazenamento e Segurança
Os dados são armazenados no **Firebase (Google Cloud Platform)** e protegidos por:

- Criptografia TLS/HTTPS
- Regras de segurança por usuário no Firestore
- Senhas criptografadas com hashing e salting
- Controle de acesso via Authentication

Não armazenamos senhas em texto puro.

## 5. Compartilhamento de Dados
Os dados do usuário **não são vendidos nem compartilhados** com terceiros para fins comerciais.

Compartilhamento ocorre apenas com:
- Firebase Authentication
- Firebase Firestore
- Firebase Cloud Messaging
- Google Gemini API (somente quando a função de IA é utilizada)

Nenhum dado é compartilhado com anunciantes.

## 6. Retenção e Exclusão de Dados
O usuário pode solicitar exclusão completa da conta.  
Ao excluir a conta:

- Os dados armazenados no Firestore são apagados permanentemente.
- Tokens de notificações são invalidados.
- Não é possível recuperar dados após a exclusão.

## 7. Direitos do Usuário (LGPD)
O usuário pode solicitar a qualquer momento:

- Acesso aos dados
- Correção
- Revogação de consentimento
- Exclusão da conta e dos dados
- Portabilidade
- Explicação sobre o tratamento
- Informações sobre compartilhamento

## 8. Cookies e Tecnologias Semelhantes
O app **não utiliza cookies**, mas utiliza:
- Tokens de autenticação Firebase
- Identificadores de dispositivo (não rastreáveis)
- Logs de segurança

## 9. Crianças e Adolescentes
O Smart Treino não é direcionado para menores de 13 anos.  
Caso seja identificado uso por menores sem consentimento dos responsáveis, a conta poderá ser removida.
